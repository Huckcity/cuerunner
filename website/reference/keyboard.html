Keyboard

Shortcuts are written for the keyboard the app is running on: Ctrl on Windows and Linux, ⌘ on macOS.

Running

KeysActionWhere
SpaceGO — fire the selected cue of the list in front and move on to the next cue of that list. With nothing selected, as after the list's last cue, it fires nothing.Anywhere except a text field
EscSTOP — stop the list in front, at once or over the show's STOP fade; a second press during the fade cuts it. Where no other list is running, that is everythingAnywhere except a text field. With a menu open, the press closes the menu and stops nothing
PPAUSE — hold the whole show where it stands, and let it go on. While it is held GO waits; STOP and PANIC end the holdAnywhere except a text field
Shift + EscPANIC — stop with a short fadeAnywhere except a text field
Ctrl/⌘ + Shift + PPANIC from the application menu — the same silence, reached without the windowAnywhere, including while the window is busy

A tile's own keyPlay that tile — set by right-clicking the tile and pressing the keyAnywhere except a text field, whichever list is in front

Editing the list

KeysActionWhere
↑ / ↓Move the selectionCue list
DeleteDelete the selected cue. The selection moves to the cue that took its place, so GO stays where you were working.Cue list
Ctrl/⌘ + DDuplicate the selected cueCue list
Ctrl/⌘ + C / X / VCopy, cut or paste the selected cues — a group with everything in it. A paste lands after the cue you stand on, as new cues with the next numbers; a copied fade aimed at a cue copied with it is aimed at that cue's copy. The copy outlives opening another show, so cues move between showsCue list; in a text field the field's own text
Enter / EscCommit or cancel a renameRenaming a cue
EscClose a menu — the row menu, Cuerunner ▾ or More ▾ — or cancel a rename; a bare press is the transport'sCue list and toolbar
Ctrl/⌘ + ZUndoAnywhere except a text field
Ctrl/⌘ + Shift + ZRedoAnywhere except a text field
Undo is one stack for everything an edit destroys — the cue list, the scenes, the desk setup, the cast, the mic plot and how the show follows timecode — so an undo is never half a change. It keeps the last 50 edits. In a focused text field, the field's own undo applies instead.
