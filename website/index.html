Quick Start

  1. Launch Cuerunner and create a workspace from Cuerunner > New.
  2. Add cues from the toolbar: Audio, Group, Fade, Wait, Stop, or More for MIDI / OSC / Network / Script.
  3. For audio, drag files directly into the cue list to auto-create cues.
  4. Select a cue to edit it in the Inspector panel.
  5. Press GO to run the selected cue and advance through your show.

That is the short version. Your first show walks it through properly, the rest of the guides cover building and running a show, and the reference has every cue type, setting and shortcut.
